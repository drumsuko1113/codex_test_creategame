将棋倶楽部2.4 手動動作確認手順

【1. 事前準備】
1) リポジトリ直下で依存関係をインストール
   npm install

2) ターミナルA（サーバー）を起動
   npx tsx server/src/index.ts

3) ターミナルB（フロント）を起動
   npm run dev

4) ブラウザで以下を開く
   http://127.0.0.1:5173

【2. オンライン対局の確認】
1) タブ1でルーム作成し、参加情報を控える
2) タブ2（シークレット推奨）で同じ対局に参加
3) 先手・後手の双方で以下を確認
   - 自分の手番でのみ操作できる
   - 着手後に盤面と手番表示が更新される
   - 投了で終局表示になる

【3. 観戦モードの確認】
1) 進行中の gameId を使って観戦開始
2) 観戦中は着手操作できないことを確認
3) 対局進行に合わせて盤面更新されることを確認

【4. Bot対局の確認】
1) Bot対局を開始
2) ユーザー着手後にBotの応手が反映されることを確認
3) 投了操作で終局できることを確認

【5. レイアウト確認（レスポンシブ）】
1) ブラウザ幅を徐々に狭める
2) 盤と駒台の位置関係、重なり、見切れ、操作可否を確認
3) 着手時に盤面が上下に揺れないか確認

【6. 補足確認（時計・同期）】
1) 時計表示の減少量が体感と大きくズレないか確認
2) 着手反映が遅延しないか確認
3) 再接続（タブ再読込）後の同期復元を確認

【7. 終了】
1) ターミナルA/B を Ctrl + C で停止
